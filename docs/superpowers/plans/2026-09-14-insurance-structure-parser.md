# 보험 약관 구조 추출 개선 계획

## 목표

보험 약관 PDF를 변환·청킹할 때 `편/장/절/관/조` 구조와 PDF 변환 중 삽입된 공백을 보존한다. 목차나 문장 중간의 조문 인용을 조문 heading으로 오인하지 않는 기존 안전장치도 유지한다.

## 구현 순서

1. 조문 번호 공백과 관 heading에 대한 회귀 테스트를 먼저 추가한다.
2. PDF 변환의 기본 경로를 보험 약관에 맞는 table-aware 변환기로 전환한다. PDF가 아닌 파일은 계속 anydoc을 사용한다.
3. `편/장/절/관` heading을 공통으로 인식하고, 조문 정규식이 `제4 조`, `제2조의 2`를 허용하도록 수정한다.
4. 조 청크에 상위 구조를 `ancestors`로 저장하고 `path`에도 반영한다.
5. 기존 테스트와 샘플 약관을 대상으로 전체 회귀 검증을 수행한다.

## 완료 기준

- PDF 기본 업로드가 table-aware 변환기를 호출한다.
- `제1관`, `제 1 관`, `## 제1관`이 관 heading으로 인식된다.
- `제4 조`, `제2조의 2`가 올바른 조문 번호와 부번호로 추출된다.
- 관 정보가 해당 조 청크의 `ancestors`와 `path`에 보존된다.
- 목차형 heading과 문장 중간 조문 인용은 계속 조문으로 인식하지 않는다.
- 백엔드 전체 테스트가 통과한다.
